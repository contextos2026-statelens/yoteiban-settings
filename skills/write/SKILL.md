予定ばんのカレンダーへの書き込み

まず汎用ルールの正本 `/home/box/agent-data/yoteiban-rules/seihon.md` を読む。版はGitの `VERSION`に従い、本文に版番号は直書きしない。

このスキルは予定ばんのスキル群の1つです。カレンダーに書く・変える・消す時、強制追加や［仮］の追加を判断する時、日時を検算する時に読みます。動く前に必ず「予定ばんの運用ルール」も読みます。大原則と安全の線は「予定ばんの運用ルール」が最優先で、他のスキルの文と食い違う時は安全な方（書かない・送らない・消さない・聞く）を選びます。ほかのスキルの【】の項目名が出てきたら、そのスキルも読みます。

【書き込み先の照合】
正本の第15章（書き込み先の照合と検算）の照合の項に従います。

【検算】
正本の第15章（書き込み先の照合と検算）の検算の項に従います。家用の空き・衝突の数え方は第22章、移動や並びの余裕は第21章の「何分で足す」に従います。所要に2割や×1.2を足して移動や並びの余裕にはしません。

【強制追加】
正本の第16章（強制追加）に従います。通知の型による幅の変更は第16章と第20章に従います。知らせる時機は第19章・第20章に従います。

【過ぎた予定】
正本の第18章（過ぎた予定）に従います。開始の時刻が文面に無い連絡には、(c)以外は当てません。(c)（家族・近い人の緊急事態の連絡）は、開始・期限の時刻が文面に無くても当てます。詳しい条件・夜の扱い・言い方は第19章も見ます。

【仮の追加】
正本の第17章（仮の追加）に従います。枠の洗い出しは第21章、他の人の確認が要る時は第11章・第24章も見ます。本人とのチャットでは、どれにするかを質問カード（ボタン）で聞き、番号つきの文字には切り替えません。カードが出せない外の出力先だけ、番号つきの文字で聞きます。

【カレンダー】
正本の第2章（大原則）と第15章に従い、強制追加と［仮］以外は、書く前に件名・日時・場所・相手・所要・推測の印・出どころを見せ、本人が質問カードで選んだ時、または「登録して」「OK」と言った時だけ書きます。番号で選んでもらうのは、カードが出せない外の出力先だけです。調整の束は、承認された項目だけ書きます。他人のカレンダーへの招待・変更・削除は本人が明示した時だけです。
書いたら、事実だけの1行で返します。ほめ言葉・連続日数・ポイントは付けません。文例：「11/18(水) 14:00に『テスト塾 面談』を書きました」。

【説明欄の書き方】
カレンダーに書く予定の説明欄は、承認して書くもの・［自動］（強制追加）・［仮］のすべてで、必ず「いつ・どこで・何を」の形で始めます。「いつ：日時／どこで：場所（移動が要る時だけ。第12章）／何を：やること」。「何を」の行は必ず入れます。やることは全部、できるだけ短く、手順が複数なら、やる順の「・」の箇条書き。「何を」が決められない時は「何を：未定（本人に確認）」と書き、推測しません。この後ろに、［仮］なら「仮・本人の確認待ち」、そして出どころ・要約1行・推測の印などを続けます。
カレンダーやNotionへの書き込みが失敗した時は、正本の第25章の6に従います。余裕を足して書く時は、所要の見積もりは中央値や「5件中4件が収まる時間」を使い、移動や並びの余裕は第21章の「何分で足す」に従います。所要に2割や×1.2を足して移動や並びの余裕にはしません。

【他の人との予定調整機能】
正本の第24章（他の人との予定調整機能）に従います。他の人の確認が要る時は、何も書かず、まず本人に聞きます。聞き方の文と送信は【推測と確認】および第11章・第4.3節・第2章に従います（確認なしの送信はしない）。返事で日時が決まりそうなら、本人に確定してよいか質問カードで聞き、本人の承認があったときだけ、通常のルールで個人用カレンダーに書きます。他の人の予定は書きません。他人のカレンダーへの招待・変更・削除は、本人が明示した時だけです。

変更の記録は Git の CHANGELOG.md に従う。
