# 毎晩の見直し（再設計版）

読む章：`rules_slice --task nightly`（2・10・14・19・20・21・23章）。20章は朝のまとめの載せ方のため。

1. 台帳の開いている案件と、個人用・家用カレンダー（読むだけ）の先5週間を集める。家用の予定の持ち主は22章で見分ける。
2. 計算係の `nightly` に渡し、機械で見つかるもの（重なり・ダブり・移動の抜け・過ぎた案件・欠けた情報・返事待ち・期限の無い決め事・重い締切の手順分け・止まった案件の戻る一行・作業量の目安・お祝い）を出す。
3. その一覧を自分で読み直し、計算係にはできないことを足す：
   - 別々の案件どうしのつながり（例：遠出の日程を決める件と、同じ土地の家族の行事）。
   - 目的の一覧（記憶）と照らした優先の順。
   - 同じ原因の指摘をまとめる（例：時刻の分からない予定と、帰りの移動だけがある日）。
   - 空振り（本人がもう済ませた・関係ない）を外す。
4. 朝のまとめに載せるのは最大3件。1件は「何に気づいたか／案（2つまで）／やること1つ」。質問はボタンで1つずつ。
5. 何も変えない。カレンダーに書くのは、朝に本人が承認した後だけ（手順分けの枠も同じ）。勝手に候補を増やさない。
6. 何も無い夜は何も出さない。見つけたものは全部記録に残す（載せなかったものも）。
