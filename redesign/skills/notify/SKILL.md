# 急ぎの3段階と知らせ方（再設計版）

読む章：`rules_slice --task notify`（2・19・20章）。この版では、急ぎかどうかを点数ではなく余裕で決める。点数は朝のまとめの並び順に使う。

## 決め方（計算係の `urgency` で出す。頭の中で計算しない）

考え方は「次の朝のまとめまで待つと、何かを失うか」。見るのは行動の締切（開始・期限から、移動と準備を引いた時刻）。

1. 家族・近い人の急変（正本の(c)）→ 今すぐ。夜も1回。
2. 本人の行動が要らない・本人がもう知っている・家族のほかの人向け → 急ぎにしない。
3. 体・安全 → 今すぐ。
4. 余裕が1時間以内 → 今すぐ。「次の朝のまとめ＋2時間」より前 → 今日中。遅れるほど取り返せない重いもの（体・お金・契約・資格・席）で24時間以内 → 今日中。その日のうちに動くもの → 朝一番。それ以外 → ふつう。
5. 登録外で時刻が文面に無い → 急ぎにしない（朝一番まで）。登録外か推測の時刻 → 1段下げる。体・安全・(c) は下げない。

## 知らせ方

- 今すぐ・今日中：昼はすぐ1通。夜は「夜の通知」の設定に従う（記憶）。朝まで待つと間に合わないものだけ夜に1回。
- 朝一番：朝のまとめの先頭に「朝一番に」。ふつう：朝のまとめ。
- 1通は3行まで（何が／いつまでに／やること1つ）と理由1行。推測には「推定」。
- 同じ件は1回。10分以内の続報は1通にまとめる。やることが変わったときだけもう1回。
- 「今すぐ」に反応が無く、締切の15分前になったら、昼だけ1回念押し（記憶の『念押し』が「しない」なら出さない）。
- 件数で止めない。1日8件を超えたら、その日1回だけ「通知が多いですか」とボタンで聞く。
- 急ぎで出してまだ片付いていないものは、次の朝のまとめに「昨日の急ぎ」として1行残す。
