# 委任送信（再設計版）

読む章：`rules_slice --task delegate`（2・11・29・30章）。

1. 委任があるかを確かめる（相手・内容の範囲・期間・送信の許可。どれか欠けたら送らない）。委任の登録は本人の承認の後だけ。
2. 文案を作る：send_flow の prepare（delegation.py の draft）。本人に文面をそのまま見せ、ボタンで「送る／直す／やめる」を聞く。確認の省略はしない。
3. 「送る」のボタンの記録を付けて approve_and_handoff を1回だけ呼ぶ。引き渡し先（グループは伝書鳩、1対1は Mac mini の iMessage）への受け渡しは、その記録の後に1回だけ。
4. 相手側の確認が来たら confirmed（送信完了）。返事が来たら返事あり。来なければ「渡し済み（未確認）」のまま。
5. 結果が分からないときは unknown にし、再送しない。may_resend が真になることは無い（照合してから本人に聞く）。
