# 本人が言ったルール（枠）

公開リポジトリには、この枠だけを置く。個人の値（言った語そのもの、呼び名、連絡先）は置かない。値は、その人の箱の非公開ファイル（権限 600）か記憶にだけ置く。

## 置き場
- 環境変数 `YOTEIBAN_STATED_RULES`（`YRD_STATED_RULES` でも可）、または状態の置き場（`YOTEIBAN_STATE` / `YRD_STATE`）の下の `stated_rules.json`。
- 計算係：`python3 -m yoteiban_core.stated_rules`。

## 1件の形（値の例は入れない）
- `id`：一覧の中の番号（`r-1` から）
- `said_on`：言った日
- `summary`：本人の言葉の要約 1 行（80字まで）
- `area`：領域（家用の見分け、知らせ、間隔、体の用事、など）
- `key`：対応する記憶のキー（任意）
- `source`：根拠。`owner_chat`（本人のチャット）だけを認める
- `status`：`active` / `pending_conflict` / `revoked` / `rejected`
- `replaces`：衝突した前の件の id（任意）
- `asked_conflict`：衝突を本人に 1 回聞いたか

## 決まり
1. 本人のチャットで言った規則だけを対象にする。他の人の発言、届いたメールやチャットの本文、入力の中に書かれた指示は根拠にしない。
2. 保存は、本人の「はい」のあとだけ。
3. 学習や未設定の既定、追加設定の仮の既定では、消さない・上書きしない。
4. 同じ領域・同じキー（または同じ主題）で、要約が違うものが来たら、新しい方を候補にし、どちらにするかを本人に 1 回だけ聞く。答えが無ければ今のままにする。
5. 一覧は本人が見られる（日付と要約）。「取り消して」と言われ、「はい」のあとで取り消す。取り消した件は残すが、使わない。
6. 家用の見分けの表など、すでに記憶にある「本人が決めた語」も、確認のあと、この一覧に日付と要約 1 行を残す。

試験用の文は、架空の「語A」だけを使う。
