# 新しい人に渡す直前の確認表

この表は、今の持ち主（または頼まれた人）が、新しい人に配る直前に使う。項目ごとに「はい」か「いいえ」で確かめる。一つでも「いいえ」なら、直してから渡す。

前の持ち主の台帳・カレンダー・記憶・言ったルール・好みのメモ・連絡先は、新しい包みに入れない。新しい人や外部に渡さない。新しい人は空から始める。

機械で読む一覧は `docs/handoff_checklist.json`。新しい持ち主が自分の箱を整える手順は、これまでどおり `docs/NEW_OWNER.md`。

## 1. 渡す前に確かめること

| 番号 | 確かめること | はい | いいえ |
| --- | --- | --- | --- |
| C01 | 公開リポジトリに個人の値（名前・メール・電話・カレンダーID・鍵・Webhook・自分の道）が無い |  |  |
| C02 | 鍵・Webhook・個人のURLが、Gitや配る文に入っていない（値は入力欄と、権限を絞ったファイルか環境変数だけ） |  |  |
| C03 | 安全の線が残っている（カレンダーへの書き込みは承認のあと／家用カレンダーには書かない／自動では送らない／買わない・払わない） |  |  |
| C04 | 初回設定で聞く項目がそろっている（薬・食事・風呂などの体の用事、使う量、心拍の知らせ、スマホの許可、連絡を受ける人、を含む） |  |  |
| C05 | 用意するものの一覧（docs/prepare_items.md）がある |  |  |
| C06 | 初回の最初に、AIなので間違えることもある、と伝える文がある |  |  |
| C07 | 本人が言ったルールの枠がある。値は人ごとの箱だけで、配る文には入っていない |  |  |
| C08 | 追加設定は、足りない質問だけをカードで聞く流れになっている |  |  |
| C09 | 家族の名簿は空から始める案内がある |  |  |
| C10 | 前の持ち主の台帳・カレンダー・記憶・言ったルール・好みのメモ・連絡先を、新しい包みに入れてない。新しい人や外部に渡していない |  |  |
| C11 | 予定ばんの12本のスキルが包みに入っている |  |  |
| C12 | 予定ばん以外のスキルの扱い（含める／枠だけ／外す）が一覧になっている。個人の値があるものは、含めていない（枠だけか外す） |  |  |
| C13 | 新しい人のカレンダー・入口・口座は、本人が自分のアカウントでつなぐ案内がある |  |  |

| C15 | 自己試験は架空データで行い、実データには書かない、と書いてある |  |  |
| C16 | 支払い・有料登録はしない、と書いてある |  |  |
| C17 | 固有値を見張る試験が通っている |  |  |

記入のしかた：確かめた結果が正しければ「はい」の欄に印を付ける。できていなければ「いいえ」に印を付け、直してからもう一度見る。

## 2. スキルの扱い

配る範囲には、予定ばんだけでなく、今のボットのほかのスキルも含めてよい。ただし公開リポジトリと配る文に個人の値は置かない。個人の値があるものは、外すか、流れだけの枠にする。本文をリポジトリに取り込む作業は、この確認表とは別に、固有値ゼロを確かめてから行う。

| スキル | 区分 | 扱い | 覚え書き |
| --- | --- | --- | --- |
| 予定ばんの運用ルール | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの初回設定 | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの自己試験 | 予定ばん | 含める | 公開リポジトリの本体。架空データだけ。 |
| 予定ばんの受け取りと振り分け | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの推測と確認 | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんのカレンダーへの書き込み | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの予定調整 | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの重要度と通知 | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの毎晩の見直し | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの対話の早道 | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの確認間隔の学習 | 予定ばん | 含める | 公開リポジトリの本体。 |
| 予定ばんの委任送信 | 予定ばん | 含める | 文の枠は本体に含む。送る許可・相手・文面・期間の登録は、新しい人が自分でする（前の持ち主の許可は移さない）。 |
| 今日の予定と未読メールの要約 | 予定ばん以外 | 含める | 読むだけ。個人の値なし。本文の取り込みは、固有値ゼロを確かめてから別の作業で行う。 |
| 研究テーマの多方向調査と統合 | 予定ばん以外 | 含める | 手順だけ。個人の値なし。本文の取り込みは、固有値ゼロを確かめてから別の作業で行う。 |
| 朝の短歌 | 予定ばん以外 | 含める | 手順だけ。個人の値なし。使うかは新しい人が選ぶ。本文の取り込みは、固有値ゼロを確かめてから別の作業で行う。 |
| 連携ボットハンズオン進行 | 予定ばん以外 | 含める | 個人の値なし。教える用事が無い人は使わなくてよい。本文の取り込みは、固有値ゼロを確かめてから別の作業で行う。 |
| プレゼント探し | 予定ばん以外 | 枠だけ | 探し方の流れだけを枠として渡す。好みの基準や過去の候補は個人の値なので入れない。新しい人が自分の基準を入れる。 |
| プレゼント好み分析ラウンド | 予定ばん以外 | 枠だけ | 評価の手順だけを枠として渡す。前の持ち主の好みメモや評価結果は入れない。 |

「含める」は、包みに入れる（本文の取り込みは固有値ゼロの確認後）。「枠だけ」は、流れの説明だけを渡し、個人の値は入れない。「外す」は、この包みには入れない。

朝の短歌とハンズオン進行は、個人の値は無い。使う用事が無い新しい人は、使わなくてよい。
